# 🌿 Daikin AI Energy Saving Simulator

AI-powered web application for analyzing and optimizing building energy consumption with real-time calculations and interactive visualizations.

## ✨ Features

- **AI-Powered Analysis** - Simulate energy patterns and identify optimization opportunities
- **Real-time Calculations** - Instant feedback on efficiency, savings, and ROI
- **Interactive Charts** - Bar, line, and pie charts for data visualization
- **Dark/Light Mode** - Seamless theme switching
- **Analysis History** - Track all previous simulations
- **Export Reports** - Download analysis data
- **Responsive Design** - Optimized for all devices

## 🛠️ Tech Stack

- **Frontend**: React, Tailwind CSS, Recharts
- **Backend**: Supabase (PostgreSQL)
- **Auth**: Supabase Auth
- **Icons**: React Icons
- **Routing**: React Router

## 📊 Key Metrics

- **Base Efficiency**: 65-85%
- **AI Efficiency**: 75-95%
- **Energy Savings**: 15-35%
- **ROI**: 2-5 years

## 🏢 Supported Buildings

Office, Hotel, Hospital, Retail, School, Restaurant, Apartment, Airport & more.

## 🚀 Quick Start

```bash
git clone https://github.com/yourusername/daikin-ai-energy-simulator.git
cd daikin-ai-energy-simulator
npm install
npm start
```

## 🔧 Environment Variables

```env
REACT_APP_SUPABASE_URL=your_supabase_url
REACT_APP_SUPABASE_ANON_KEY=your_supabase_anon_key
```
